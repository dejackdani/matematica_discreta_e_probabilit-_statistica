# Matematica Discreta e Probabilità Statistica

Questo progetto funge da wiki, repository di appunti e sistema di generazione flashcard (AOSR) per il corso di Matematica Discreta e Probabilità Statistica. L'obiettivo è strutturare il materiale didattico in un formato facilmente interrogabile e memorizzabile.

## Installation

Non è necessaria alcuna installazione di pacchetti software per consultare il progetto. È sufficiente clonare il repository e aprirlo con [Obsidian](https://obsidian.md/) o qualsiasi altro editor compatibile con Markdown.

```bash
# Clona il repository locale o remoto
git clone <url-del-repository>
```

Successivamente, apri la directory clonata come un "Vault" all'interno di Obsidian.

## Usage

Il progetto è strutturato per essere navigato facilmente:

- Le informazioni strutturate e rielaborate vengono salvate nella directory `wiki/`.
- Tutto il materiale generato e multimediale finisce in `raw/assets/`.

Esempio di consultazione: apri un file all'interno della `wiki/` per leggere definizioni, teoremi e concetti legati al corso.

## Contributing

Per contribuire, è fondamentale seguire le regole rigide di inserimento, documentate nella cartella `.agents/`. In particolare:
1. **Strict Sourcing**: Non introdurre concetti o nomenclature non presenti nel materiale del docente.
2. I file `README.md` e `log.md` devono sempre essere mantenuti aggiornati.
3. Tutti gli asset vanno in `raw/assets/`.
